# Pull Requests — Ingestão de 11/10/2026

Esta pasta reúne os dados de pull requests gerados pela ingestão realizada em 11 de outubro de 2026.

## Finalidade

Os arquivos preservam os resultados da execução em formatos complementares:

- JSON com as respostas brutas recebidas da API;
- Parquet com os registros estruturados para processamento posterior.

---

## Estrutura

| Conteúdo | Descrição |
| --- | --- |
| Arquivos `.json` | Respostas da API associadas às execuções de ingestão |
| Arquivos `.parquet` | Dados tabulares estruturados correspondentes às execuções |
| `.gitkeep` | Marcador para preservar a pasta no repositório sem os dados gerados |

## Observações

Os arquivos JSON e Parquet são artefatos gerados e ignorados pelo Git. A pasta é identificada pela data de ingestão no próprio nome do diretório.
