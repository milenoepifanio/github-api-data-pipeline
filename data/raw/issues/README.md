# Issues — Dados Brutos

Esta pasta organiza os dados de issues obtidos da API do GitHub e armazenados na camada Raw.

## Finalidade

Os resultados são particionados por data de ingestão e podem incluir:

- respostas da API preservadas em JSON;
- dados estruturados em Parquet;
- arquivos identificados pelo repositório e horário de ingestão.
